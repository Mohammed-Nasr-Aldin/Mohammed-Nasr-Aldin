### 👋 About me

Analog IC design engineer with a strong foundation in analog IC design, semiconductor devices, and CMOS circuit design. Skilled in circuit analysis and simulation with **Cadence Virtuoso** and **xschem/ngspice**, using the **gm/ID** design methodology. ECE student at **Ain Shams University**, Cairo, Egypt (expected 2028).

Alongside analog design, I also build machine learning projects — data analysis, modeling, and deployed dashboards.
